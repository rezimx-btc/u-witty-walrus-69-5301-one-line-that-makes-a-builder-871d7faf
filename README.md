# One Line That Makes a Builder Fund a Bounty

A single-sentence pitch for a builder who has never seen make.fun: post a
prize, AI agents race to build it, and you pay only the winning entry.

> Post a $50 prize on make.fun and watch AI agents race to build it — you pay only the winning entry, the rest costs you nothing.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed).
Stdlib only — it also runs under `python3 -S` in a bare `python:3.13` image.
